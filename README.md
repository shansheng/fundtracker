# FundTracker · 本地基金追踪

一个**本地运行**的基金持仓追踪应用，类似"养基宝"。支持通过
**支付宝 / 京东金融 / 腾讯理财通** 的基金持仓截图与交易截图（OCR）更新持仓，
并在股票开盘时段，根据基金**季报/年报**披露的持仓股票及占比，结合**盘中实时行情**
估算本人基金的实时涨跌幅。

## 特性

- 桌面应用（Electron），数据全部存于**本地 SQLite**，不上传任何云端。
- 三平台截图 OCR 自动识别持仓 / 交易，识别结果可逐项确认、修正后入库。
- 自动从公开接口拉取：
  - 基金最新净值与基础信息（天天基金 / 东方财富）
  - 基金季报 / 年报持仓股票及占比（东方财富 F10）
  - 成分股**实时涨跌幅**（新浪财经，失败自动回退东方财富）
- 实时估算涨跌幅：`Σ(成分股占净值比例 × 成分股实时涨跌幅)`，并汇总组合总市值、当日盈亏、累计收益。
- 自动判断交易时段（盘中每 10 分钟刷新估值）。

## 技术栈

| 模块 | 选型 | 说明 |
| --- | --- | --- |
| 桌面壳 | Electron | 跨平台，处理窗口与本地文件 |
| 本地数据库 | sql.js (WASM 版 SQLite) | 零原生编译依赖，持久化到本地文件 |
| 后端 API | Express | 本地 `127.0.0.1:3456`，仅本机访问 |
| OCR | tesseract.js | 本地中英文 OCR，首次运行下载语言包 |
| 行情/基金数据 | 新浪 / 东方财富公开接口 | 无需注册 key |

> 说明：早期版本使用 `better-sqlite3`，但在部分环境因 C++ 编译器过旧无法原生编译，
> 已改用纯 JS 的 `sql.js`，无需编译即可在任何平台运行。

## 安装与运行

> 需要 Node.js 18+（已内置 `fetch`）。本应用在**你自己的电脑**上运行，
> 需能访问外网以拉取行情与基金数据。

```bash
# 1. 安装依赖（若之前有残留 node_modules，建议先 rm -rf node_modules）
npm install

# 2. 启动桌面应用（会自动拉起本地 API 服务并打开窗口）
npm start
```

仅启动后端 + 浏览器访问（开发调试用）：

```bash
npm run server
# 浏览器打开 http://127.0.0.1:3456
```

## 使用流程

1. **添加基金**：在「基金/持仓管理」输入基金代码（如 `110011`），点击"添加并拉取持仓"。
   应用会从公开接口拉取净值与最新一期季报/年报的持仓股票及占比。
2. **截图更新持仓 / 交易**：在「截图更新」选择平台与截图类型，上传支付宝/京东/理财通截图，
   点击"识别"。OCR 结果会列出，请核对基金代码、金额、份额、日期后点击"保存到数据库"。
3. **查看实时估值**：「持仓概览」展示每只基金的估算净值、估算涨跌幅、市值、当日盈亏与累计收益，
   点击"明细"可展开成分股贡献。盘中每 10 分钟自动刷新。
4. **交易记录**：所有保存的买入/卖出记录在此汇总。

## 实时估值原理

- 数据源：基金最近一期季报 / 年报披露的"占净值比例"（来自东方财富 F10）。
- 估算涨跌幅 = `Σ(披露成分股_i 占比 × 成分股_i 实时涨跌幅)` + `剩余仓位占比 × 基准指数当日涨跌幅`。
- 季报通常只披露前十大重仓（合计约 30%~90%），**未披露部分按基金所属行业 / 宽基指数
  （`track_index`，缺省为沪深300）当日涨跌补齐**，而非简单视作 0 波动 —— 否则估算会系统性偏低。
- 债券 / 货币 / QDII 基金无适用的权益基准，其剩余仓位仍近似为 0 波动（债券 ≈ 低波动、QDII 跟踪海外资产）。
- 单只基金的 `track_index` 可在"基金/持仓管理"经 API 逐只覆盖为更精确的行业指数（如医药、银行、券商等）。
- 组合总市值 = `Σ(持有份额 × 最新净值 × (1 + 估算涨跌幅))`。

## API 一览（本地）

- `GET  /api/estimate`            组合实时估算
- `GET  /api/funds/:code/estimate` 单基金估算明细
- `GET  /api/funds` / `POST /api/funds`         基金列表 / 新增
- `POST /api/funds/:code/refresh`              拉取基金净值+季报持仓
- `GET  /api/holdings` / `POST /api/holdings`  持仓
- `GET  /api/transactions` / `POST /api/transactions` 交易记录
- `GET  /api/quotes?codes=sh600519,sz000001`    实时行情
- `POST /api/ocr`               截图 OCR 识别（传 file_path）
- `POST /api/upload`            上传截图文件

## 注意事项

- OCR 识别准确率受截图清晰度与平台排版影响，请务必在保存前**核对**识别结果。
- 公共行情接口可能随时变动或限频；若某接口失效，代码已做新浪→东方财富回退。
- 所有数据存于用户目录（Electron `userData` 或 `~/.fundtracker/fundtracker.sqlite`）。
